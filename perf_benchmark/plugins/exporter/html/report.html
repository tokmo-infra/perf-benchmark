指标口径与比较条件

TTFT 是客户端请求开始到首个文本输出事件的时间；ITL 是相邻文本输出事件的间隔。SSE chunk、输出事件与 token 不等价，这些客户端时间不能直接解释为服务端 prefill、decode 或 GPU 执行时间。

TPOT 的 token 分母来自服务端 usage；usage 缺失时保留不可用状态，不用输出事件数估算 token。非流式或非文本响应的 TTFT、TPOT、ITL 及 prefill/decode throughput 按 unavailable 显示原因，E2E 仍按已观测到的请求起止时间计算。

请同时查看有效 / 预期样本、分组成功资格及缺失原因；少量有效样本不能代表全部请求。容量判断还需要负载有效性和 SLO 证据。跨 Run 或工具比较时，应对齐协议与流式设置、数据与 tokenizer、测量窗口、指标定义及成功 / 失败请求的统计资格。
